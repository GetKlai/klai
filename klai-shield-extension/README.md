# Klai Shield Extension

Platform-admin-only browser extension for Klai Shield, based on the Superdock
extension shell and wired to Klai auth, compliance, and knowledge APIs.

## Load locally

1. Open `chrome://extensions`.
2. Enable developer mode.
3. Choose **Load unpacked** and select this `klai-shield-extension` folder.
4. Open the Klai Shield side panel.
5. Click **Inloggen met Klai**.
6. Complete the Klai login flow with a platform-admin account.

The extension checks prompts in supported browser LLMs and can insert Klai
knowledge context into the active composer.
